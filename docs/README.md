# Cẩm nang học GitHub

Tài liệu tiếng Việt dành cho người mới hoặc cần học lại GitHub, với ví dụ trên kho DQY.

- [Bản Word — có thể chỉnh sửa](Cam-nang-GitHub.docx)
- [Bản PDF — đọc và in](Cam-nang-GitHub.pdf)

Tài liệu gồm 18 chương, khoảng 48 trang: thao tác trên web, GitHub Desktop, lệnh Git, nhánh và pull request, làm việc nhóm, xử lý lỗi, bảo mật, tài liệu Word, Actions và Pages. Có bài thực hành DQY, bảng tra cứu và lộ trình học 21 ngày.

## Cách tải

1. Mở liên kết Word hoặc PDF phía trên.
2. Nếu kho yêu cầu quyền truy cập, đăng nhập đúng tài khoản GitHub.
3. Trên trang tệp, bấm **Download raw file** (biểu tượng tải xuống) hoặc **View raw** theo giao diện hiện tại.
4. Lưu tệp về máy rồi mở bằng Word hoặc ứng dụng đọc PDF.

Bắt đầu ở phần **Bắt đầu từ đây**, rồi đọc chương 1–5 trước. Các bài trong tài liệu là hướng dẫn thực hành; chúng không xác nhận rằng ứng dụng của DQY đã được triển khai.
